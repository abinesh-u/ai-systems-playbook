# Visual Production Playbook

1. Content Production identifies a visual requirement and reader question.
2. Create a specification; assign category, owner, evidence, and reuse search.
3. Plan components, relationships, layout, accessibility, and export.
4. Run architecture, editorial, accessibility, and visual review.
5. Version source, publish export, attach caption/alt text, and update cross references.

Integration: Knowledge Architecture supplies pillar/hub ownership; Editorial System supplies diagram and accessibility standards; Content Intelligence decides duplication/reuse; Content Production requires the specification in the publication package.
