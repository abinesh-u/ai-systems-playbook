# Diagram Specification Standard

Every planned visual uses this format before artwork or rendering:

```yaml
---
id:
title:
category:
pillar:
hub:
article:
status: planned
version: 0.1.0
owner:
---
```

Required sections: Purpose; Audience; Components; Relationships; Layout; Legend; Color Mapping; Accessibility Notes; Prompt/Source Instructions; Review Checklist; Reuse Opportunities; Evidence and Limits. Store specifications in `visual-library/specifications/` and editable templates in `visual-library/templates/`.
