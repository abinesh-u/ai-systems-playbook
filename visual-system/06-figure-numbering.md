# Figure Numbering

ID format: `fig-<pillar>-<category>-<ordinal>`; example: `fig-agent-systems-flow-001`.

Filename format: `<id>-<slug>-v<major.minor.patch>.<ext>`. Captions begin `Figure <ordinal>.` and describe scope, not conclusions. Articles reference IDs, never unversioned filenames. Ordinals are article-local; IDs are repository-global.
