# Visual Taxonomy

| Category | Primary question |
| --- | --- |
| Architecture | What owns which responsibility and boundary? |
| Sequence | In what order do actors interact? |
| Flow | How does work or data move? |
| Comparison | How do alternatives differ under stated criteria? |
| Decision tree | Which choice follows which conditions? |
| Timeline / lifecycle | How does state change over time? |
| Concept | What mental model connects the concepts? |
| Reference illustration | What stable component or pattern is being identified? |

Choose one primary category; secondary tags do not replace it.
