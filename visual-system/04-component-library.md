# Component Library

| Component | Meaning | Required label |
| --- | --- | --- |
| System boundary | owned scope | system name |
| Service/process | responsibility | verb or role |
| Data store | persisted state | data type/owner |
| External dependency | outside boundary | dependency name |
| Actor | human or system initiator | role |
| Decision | branching condition | question |
| Artifact | input/output/evidence | artifact name |

Do not invent component shapes per article. Add a new component only through visual review.
