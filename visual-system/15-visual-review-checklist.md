# Visual Review Checklist

- [ ] Specification, purpose, owner, evidence, and limits are complete.
- [ ] Category, component shapes, arrows, labels, and layout match the visual system.
- [ ] Boundaries, inputs, outputs, ownership, and legend are unambiguous.
- [ ] Caption, figure ID, alt text, and text equivalent are present.
- [ ] Contrast, readability, licensing, source, version, and export meet standards.
- [ ] Article, pillar/hub, Reference Library, and reuse links are correct.
