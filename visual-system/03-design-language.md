# Design Language

- Components: rounded rectangles for services/processes; cylinders for stores; documents for artifacts; bounded groups for systems.
- Relationships: solid arrow for flow; dashed arrow for optional/control relationship; labelled arrows for non-obvious semantics.
- Labels: sentence case, concise nouns/verbs, no unexplained acronyms.
- Direction: left-to-right for flow; top-to-bottom for hierarchy.
- Captions state the visual’s question and scope. Cross references use figure IDs.
- Use the smallest diagram that answers the question.
