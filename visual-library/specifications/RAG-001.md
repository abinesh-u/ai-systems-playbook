# RAG-001 — RAG foundations retrieval pipeline

## Purpose

Show the bounded flow from an incoming query through embedding, retrieval, optional reranking, context assembly, and answer generation. The visual must establish the interfaces and decision points discussed by the article without prescribing a universal implementation.

## Layout

Left-to-right, single primary path. Place the corpus/index below the retrieval stage as a persistent data store. Render optional reranking as a labelled conditional stage between retrieval and context assembly. Keep model generation within a distinct inference boundary. Do not show vendor products, performance values, or implementation-specific storage choices.

## Components

| Component | Visual component | Label |
| --- | --- | --- |
| Input | actor/input artifact | User query |
| Query representation | service/process | Query embedding or representation |
| Retrieval | service/process | Retrieve candidate passages |
| Index | data store | Indexed retrieval units |
| Optional refinement | service/process | Optional reranking |
| Context | artifact | Selected context |
| Generation | service/process in inference boundary | Generate grounded response |
| Output | artifact | Response |

## Relationships

- User query → query representation → candidate retrieval.
- Retrieval reads indexed retrieval units.
- Candidate passages → optional reranking → selected context.
- Selected context and user query → generation → response.
- Label the reranking bypass explicitly as “when used”; it is not a required architecture component.

## Legend

- Rounded rectangle: process/service.
- Cylinder: persisted retrieval index.
- Document shape: input, context, or output artifact.
- Solid arrow: data/control flow.
- Dashed arrow: optional path.
- Bounded group: inference boundary.

## Color Mapping

- Blue: processes/services.
- Green: indexed or selected data artifacts.
- Amber: optional reranking decision/path.
- Gray: user input and external context.
- Use labels and line styles in addition to color.

## Accessibility Notes

Alt text: “A left-to-right RAG flow where a user query is represented for retrieval, retrieves candidate passages from an indexed corpus, may pass through optional reranking, becomes selected context, and is combined with the query by a generation component to produce a response.”
